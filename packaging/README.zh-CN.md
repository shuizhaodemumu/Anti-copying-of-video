# 60 Hz 屏幕实拍对照 0.4.1

程序内置黑白文字页和带中文字幕的 10 秒无声短片。打开时先显示原画，预选「翻拍暗字」（**5**），沿用 0.3.0 的交替配色算法。两个暗字档都在文字页按三行三列排列，每个格内有一组暗字。视频保留上方中央的一组暗字。

「减闪暗字」（**6**）让相邻两次刷新使用接近等亮度的一对颜色。字形只决定两种颜色的显示顺序。同一像素的两帧等量叠加后，暗字笔画与背景采用相同的配色规则。短曝光偏向其中一帧时，手机可能拍出暗字。现场能否察觉字形、闪动程度以及录像清晰度仍需实拍比较。

## Fedora 45 x86_64 安装或升级

关闭正在运行的旧版，在 RPM 所在的目录执行以下命令。安装过 0.4.0 的系统可用同一命令升级。

```sh
sudo dnf install ./photo60-test-0.4.1-1.fc45.x86_64.rpm
photo60-test
```

桌面菜单中可搜索「60 Hz 屏幕实拍对照」。卸载时运行 `sudo dnf remove photo60-test`。

## 实拍对照

1. 将显示器设为固定 60 Hz。保持同一亮度、机位和对焦，先用上一轮比较过的录像设置录下几秒原画。
2. 按 **空格** 开启默认的「翻拍暗字」，几秒后按 **6** 切到「减闪暗字」，按 **5** 返回默认档，按 **Esc** 恢复原画。每一档先在平常的阅读距离观察文字页各格内有无字形、正文是否闪动，再看录像同一位置。观察者若事先不知道字样，可以记录实际能读出几个字。
3. 同样的操作可分别用于手机的 24、30 和 60 帧录像。每帧曝光时间和曝光开始时刻会影响录到的颜色。即使录制 60 帧，当曝光恰好等量跨过两次刷新时，暗字也可能消退。
4. 按 **1** 看文字页，按 **2** 播放字幕短片。可暂停在同一帧比较，或按 **R** 回到片头。按 **3** 选标准档、**4** 选增强档、**F11** 切换全屏。程序检测到刷新持续不稳时会返回原画。

## 从源码构建

在 Fedora 安装构建工具，解压源码归档后进入项目目录。

```sh
sudo dnf install cargo rust gcc gtk4-devel desktop-file-utils python3 rpm-build
./packaging/build-rpm.sh
```

构建脚本依照 Cargo.lock 获取依赖，随后离线编译。生成的 RPM 和源码归档位于 `dist/`。也可用 `cargo run --release --locked` 运行程序。源码已包含文字页、视频与暗字遮罩。
